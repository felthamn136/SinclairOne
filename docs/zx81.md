# ZX81 components

`sinclair-zx81` is a machine boundary and a set of independently usable
components, not yet a running ZX81 emulator. Supply a legally obtained 8 KiB
ZX81 ROM to `Zx81::new`, and select `RamSize::OneK` or `RamSize::SixteenK`.
The ROM and RAM follow the standard 1K or 16K mirrored address map.

The shared `Machine` interface accepts keyboard input and in-memory save
states, including the ROM identity, RAM configuration and any mounted WAV
tape. It accepts a `.p` program through `Media` with format `p`; this validates
the image length and directly copies its saved RAM range, rather than running
the ROM's cassette loader. The 1K configuration rejects images that do not fit.
The host is responsible for a valid surrounding machine state. Format
`p-tape` instead mounts the image as an unnamed cassette signal with a
five-second leader and ZX81 bit bursts; use it with an unnamed ROM `LOAD`.

Format `wav` mounts an 8- or 16-bit PCM, mono or stereo WAV. `WavTape` exposes
the sampled EAR level and advances at the 3.25 MHz ZX81 clock, preserving
fractional sample timing and playback position in save states. Instruction
stepping samples EAR at the start of each instruction; mounting WAV alone
does not load a program. Unsupported encodings and malformed files return
errors.

`video::render_display` renders the conventional 24-row display file and the
character set in the supplied ROM, including collapsed 1K rows and inverse
characters. It is a snapshot renderer, not cycle-timed ULA video; it does not
represent custom display routines or FAST/SLOW mode.

`step_instruction` runs the Z80, keyboard and tape with an instruction-level
approximation of the ULA's NMI and A6 interrupts. This does not model
within-instruction signal timing, WAIT, or complete ULA sync generation.
The machine's `run_frame` returns `Unsupported`. Timed ULA video, frontend
controls, and complete FAST/SLOW behavior remain unimplemented. Consequently
booting to the K prompt and actual tape or WAV program loading have not been
verified. No ROM is distributed.

Run `cargo test -p sinclair-zx81` for component and state tests. The Z80
acceptance tests also cover the opcode-fetch callback needed for ZX81 video.
